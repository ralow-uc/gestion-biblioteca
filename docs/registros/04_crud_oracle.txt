 Registro: CRUD del microservicio contra Oracle (perfil 'oracle')
 Microservicio gestion-biblioteca
===========================================================================

Base      : FULLSTACK3 (Oracle Autonomous Database)
Servicio  : fullstack3_tp  (TNS alias del Wallet, conexion mTLS)
Motor     : Oracle AI Database 26ai Enterprise Edition 23.26.4.1.0
Arranque  : ./scripts/run-oracle.sh

Hibernate arranco con spring.jpa.hibernate.ddl-auto=validate: el mapeo JPA
de la entidad Libro coincide con la tabla LIBRO real de Oracle.
